🚀 Deployment Guide

Complete guide to run Image Search Service in production

1 Server Requirements

ResourceMinimumRecommended
RAM4 GB8 GB
CPU2 cores4 cores
Disk20 GB50 GB
OSUbuntu 22.04 LTS

Works on: DigitalOcean, AWS EC2, Hetzner, Linode, Vultr.

2 Install System Packages

Connect to your server and run:

ssh root@your-server-ip

apt update && apt install -y python3 python3-pip python3-venv git docker.io nginx
systemctl enable docker && systemctl start docker

3 Upload Project to Server

Option A — SCP (direct copy):

scp -r /Users/rarashed/Desktop/imageSearch root@your-server-ip:/app/imageSearch

Option B — Git:

# On your local machine
git init && git add . && git commit -m "init"
git remote add origin https://github.com/yourname/image-search.git
git push

# On the server
git clone https://github.com/yourname/image-search.git /app/imageSearch

4 Start Qdrant Database (Docker)

docker run -d \
  --name qdrant \
  --restart always \
  -p 6333:6333 \
  -v /app/imageSearch/qdrant_storage:/qdrant/storage \
  qdrant/qdrant
💡 The -v flag mounts your existing qdrant_storage/ folder — all uploaded vectors are preserved.

5 Setup Python Environment

cd /app/imageSearch
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

Test it works before creating the service:

python -m uvicorn main:app --host 0.0.0.0 --port 8000

6 Run as a Service (systemd)

Create the service file:

nano /etc/systemd/system/imagesearch.service

Paste this content:

[Unit]
Description=Image Search API
After=network.target

[Service]
User=root
WorkingDirectory=/app/imageSearch
ExecStart=/app/imageSearch/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --workers 2
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

Enable and start:

systemctl daemon-reload
systemctl enable imagesearch
systemctl start imagesearch
systemctl status imagesearch

7 Nginx Reverse Proxy (optional)

nano /etc/nginx/sites-available/imagesearch
server {
    listen 80;
    server_name your-domain.com;

    client_max_body_size 20M;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
ln -s /etc/nginx/sites-available/imagesearch /etc/nginx/sites-enabled/
nginx -t && systemctl restart nginx

9 Logs & Monitoring

# Live API logs
journalctl -u imagesearch -f

# Check service status
systemctl status imagesearch

# Restart after code update
systemctl restart imagesearch

↻ Server Restart Commands

Production (systemd service):

# Restart API server
systemctl restart imagesearch

# Stop API server
systemctl stop imagesearch

# Start API server
systemctl start imagesearch

# Restart Qdrant database
docker restart qdrant

# Restart both API + Qdrant
systemctl restart imagesearch && docker restart qdrant

Local development:

# Stop running server with Ctrl+C, then:
source venv/bin/activate
python -m uvicorn main:app --reload
💡 After uploading new code to the server, always run systemctl restart imagesearch to apply changes.
